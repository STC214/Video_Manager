# File Manager

`File Manager` 是 `Video Manager` 仓库内的独立子项目。它沿用原项目的原生 Win32 深色 UI 和安全移动流程，用可配置文件后缀整理任意类型的文件。

## 目录规则

目录固定为四层：

```text
目标目录/
  2021/
    2021S3/
      202107/
        20210701/
```

- 第 1 层：从“起始年份”开始的四位年份。
- 第 2 层：该年份的季度，固定为 `YYYYS1` 到 `YYYYS4`。
- 第 3 层：月份，固定为 `YYYYMM`。
- 第 4 层：月内叶目录，固定为 `YYYYMMNN`，`NN` 从 `01` 开始。
- 每月叶目录数量全局统一设置。
- 每个叶目录的最大目标文件数量全局统一设置。
- 文件按最后修改时间从早到晚分配；时间相同则按相对路径和文件名稳定排序。

## 后缀设置

支持逗号、分号、空格和中文标点分隔，大小写不敏感，点号可以省略，也支持 `.tar.gz` 等复合后缀。例如：

```text
.jpg, png；PDF
```

扫描只把这些后缀计为目标文件，其他文件只统计、不移动。多个后缀同时匹配时优先采用最长后缀。

## 工作流

1. 选择源目录和目标目录。
2. 设置后缀、起始年份、每月叶目录数、每叶文件数。
3. 扫描，UI 自动显示目标文件数和容量计算结果。
4. 生成 Dry-run，检查分页预览和 TSV。
5. 确认后正式移动；需要时可按运行清单撤销最近一次移动。

目标重名会自动追加 `_dup001`。正式移动优先使用重命名；跨盘时使用复制、大小及时间校验后再删除源文件。

再次整理到已有目标目录时，Dry-run 会统计现有叶目录中的匹配文件，从第一个未满叶目录继续分配。正式移动每个文件前还会重新读取叶目录容量；若其他程序或网络用户在 Dry-run 后改变了容量，本次计划会停止并要求重新生成。

SMB、UNC 和网络映射盘的目录选择、扫描、校验及规划均在独立线程执行。目录选择器可通过主窗口取消，关闭程序也不会无限等待 Shell 对话框。扫描会逐层重试目录读取，包括网络暂时返回的“路径不存在”。网络 Dry-run 在目标规划和源目录空目录预览全部完成前保持持续动画；网络移动和撤销在单文件 I/O 期间也显示跑马灯。这些等待均不会阻塞主窗口消息循环。

## 构建与测试

在仓库根目录运行：

```powershell
go test ./file-manager/...
.\file-manager\build.ps1
```

构建输出为 `file-manager\dist\FileManager.exe`。运行配置保存在 EXE 同目录的 `file-manager-data\config.json`。
