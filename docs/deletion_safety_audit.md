# Video Manager 文件删除边界审查

本页审查的是根目录 `cmd/video-manager` 构建的 Video Manager 主程序。仓库内 `file-manager` 是独立子项目，其规则与验收需分别评估。

## 结论与保证边界

主程序没有递归删除文件或覆盖目标文件的归档路径。正常归档、投料和撤销的文件路径变化属于**移动**：同卷采用不覆盖目标的重命名；跨卷仅在新目标副本通过校验后删除本次移动的源文件。清理阶段只尝试删除已确认属于扫描范围、且仍为空的子目录，不删除源根目录或目标目录。Dry-run 不删除源文件。

这是基于当前源码、自动化测试和受控文件系统行为的审查结论，不是对断电、磁盘损坏、SMB 服务异常、外部进程同时改写文件、被篡改的运行清单或所有文件系统实现作无条件保证。扫描时会冻结文件对象身份并带入内存移动计划，正式移动和投料目标复审会比较身份，覆盖同大小、同修改时间的常见替换场景。TSV 和旧运行清单仍只保存路径、大小、修改时间，不含对象身份；文件系统复用标识或最后一次校验与移动/删除之间的并发窗口仍需防范。重要数据在正式移动前应保留独立备份，并避免其他程序同时修改源目录。

## 删除入口与触发条件

| 入口 | 触发条件 | 删除对象 | 保护措施 |
| --- | --- | --- | --- |
| `mover.go` 跨卷回退 | 不覆盖重命名失败，副本已完整写入并验证 | 原计划中的单个源文件 | 大小、修改时间、文件身份与 SHA-256 复核；按已打开对象身份删除 |
| `mover.go` 失败回收 | 临时复制失败，或副本发布后源文件删除失败 | 本次创建的临时文件或已发布副本 | 仅清理本次创建且身份一致的文件；异常状态保留待恢复清单 |
| `cleanup.go` | 成功移动后遍历源目录 | 空的源子目录 | 不处理源根目录、受保护目标、非空目录、普通文件；按目录对象身份删除 |
| `undo.go` / `structure.go` | 确认撤销且所有文件恢复 | 本次绑定的结构记录及意图文件 | 绑定运行、哈希、基线快照、文件身份复核；后续投料仍依赖时延迟清理 |
| `appconfig/config.go` | 保存配置 | 旧 `data/config.json` 由原子重命名替换 | 只更新程序配置；失败时独有临时文件保留，不按路径删除 |

同卷不覆盖重命名会使源路径消失，但不调用删除；撤销时执行反向移动，因此归档位置的文件也会从原路径消失。上述两者都是用户确认的移动行为。非视频文件不会进入主程序移动计划；但**已经为空**的源子目录会被清理，因此空目录本身不保证保留。

## 执行链路

1. 扫描和 Dry-run 生成明确的源/目标文件映射与 TSV，内存计划同时保留扫描时的文件对象身份；投料前还会核对保存的结构参数、真实目录树和每叶文件数，配置或路径改变会让旧计划失效。
2. 用户在确认弹窗中批准正式移动；目标锁串行化同一目标的写入和撤销。
3. 每个文件执行前重新检查源文件大小、修改时间和对象身份；目标采用不覆盖发布。
4. 跨卷复制先写入独有临时文件，再比对复制流、当前源文件和目标临时文件的 SHA-256，同时检查大小、时间和权限，最后发布副本并删除同一源对象。校验失败时保留源文件。
5. 已同步的运行清单记录每项待处理/完成状态；不确定的已发布副本保留恢复提示，不伪报完成。
6. 空目录清理只在移动无错误时执行；逐个确认目录仍为空、对象未被替换，且只遍历源根目录以下、跳过受保护目标。

## 已验证用例

- 源文件在扫描后被同大小、同修改时间的新对象替换，或执行中被替换、改大小、改时间，或跨卷复制中在相同大小与修改时间下改内容时，受控测试均拒绝本次移动或删除。
- 复制目标时间/模式保存失败、重名目标晚于 Dry-run 出现、只读源文件跨卷时，不删除源文件。
- 已发布副本回收不删除路径上的其他文件；空目录路径被替换为新目录或普通文件时，不删除新对象。
- 非空目录和源根目录保留；撤销时结构记录只在拥有者和基线条件符合时清理。

运行 `go test -count=1 ./...`、`go test -race -count=1 ./...`、`go vet -unsafeptr=false ./...` 和 `git diff --check` 可复核自动化部分。人工验收仍需在真实本地盘与 SMB/NAS 的副本数据上测试权限、断线、锁文件、取消和断电后的恢复。
